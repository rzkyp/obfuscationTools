## Tentang

Alat obfuscation sederhana untuk kode C dan PHP. Output dikompresi dengan zlib lalu di-encode base64 berlapis.

## File

- `obC.py` — obfuscator untuk kode C
- `obPHP.py` — obfuscator untuk kode PHP

## Pakai

```bash
python obC.py
python obPHP.py
```

## Disklaimer

Gunakan hanya pada kode milik sendiri. Obfuscation bukan pengganti praktik keamanan yang baik.
